# CyberSecurity_Lab_Management
* **Project Title:** Cybersecurity Lab Report
* **Student Name:** Fabeha Faisal
* **Student ID:** 26K-2008
* **Project Description:** This C program is designed as a laboratory information management prototype for a university cybersecurity lab. It collects and processes information about the lab's hardware, network infrastructure, and security software/tools. The program calculates the estimated costs and generates a structured financial investment report.
* **Input:** The program accepts the following information:
* Lab Name
* Number of Computers
* Number of Network Devices
* Number of Security Tools
* Cost per Computer
* Cost per Network Device
* Total Software/Security Tools Cost
* **Processing:** The program performs the following calculations:
* Total Computer Cost = Number of Computers × Cost per Computer
* Total Network Cost = Number of Network Devices × Cost per Network Device
* Total Lab Investment = Total Computer Cost + Total Network Cost + Software/Security Tools Cost
* **Output:** The program displays a structured financial report containing:
* Lab name
* Hardware inventory
* Network device inventory
* Security tools/software information
* Individual cost calculations
* Total computer cost
* Total network cost
* Total software cost
* Overall estimated lab investment
* **How to Compile:** The program can be compiled and executed using GCC (GNU Compiler Collection) or any standard C compiler.
